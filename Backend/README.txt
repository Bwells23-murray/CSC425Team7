A simple API for CRUD operations for users and messages.

How To Use: 
-Clone repository:
https://github.com/Bwells23-murray/CSC425Team7.git
-cd into backend
-Create .env file with Database URI and set Port to 3000
-npm install
-npm run dev
-use Postman for database interaction

FEATURES:
-Create users/messages
-Update users/messages
-Delete users/messages by id
-Retreive users/messages
